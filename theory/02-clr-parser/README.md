# Theory 02: CLR(1) Parser Automaton

## What it is

This assignment asked for the canonical LR(1) automaton for a grammar built from the student ID. The work covers the production rules, the item sets and the transitions between them.

The task sheet is in `docs/assignment-02.pdf`. The scanned handwritten submission is `submission.pdf`.

## Note

The submission was written by hand and scanned. There is no typed version of the automaton in this repo.
