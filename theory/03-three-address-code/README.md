# Theory 03: Three-Address Code

## What it is

This assignment asked for one attribute grammar that combines the syntax-directed translation rules for declarations, expressions, assignments, array accesses and control flow. The report also shows a sample program, its abstract syntax tree, the symbol table entries and the three-address code.

The task sheet is in `docs/assignment-03.pdf`.

## Files

- `report.pdf`: 24-page report with the rules and the worked example
- `attribute-grammar.docx`: source document for the report

## Note

The report uses a phase flag for the three passes: symbol table population, label setup and code generation.
