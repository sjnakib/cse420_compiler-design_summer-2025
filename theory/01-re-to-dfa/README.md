# Theory 01: Regular Expression to Direct DFA

## What it is

This was the first self-study theory assignment. The task was to convert a regular expression into a DFA with the direct construction method from the reference textbook. The steps are the expression tree, NULLABLE, FIRSTPOS, LASTPOS, FOLLOWPOS and the final DFA table.

The task sheet is in `docs/assignment-01.pdf`.

## Note

The assignment required a handwritten hard copy. The handwritten submission is not included in this repo. Only the task sheet is kept here.
